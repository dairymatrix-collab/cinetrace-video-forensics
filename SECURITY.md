# Security Policy

CineTrace is an offline-first analysis workflow and does not need credentials for local probing. Treat all analyzed media, transcripts, captions, metadata and public-page text as potentially untrusted.

Do not publish private media, credentials, personal data, or exploit details in issues. Report a security concern privately through the repository's GitHub security contact after publication, or open a sanitized high-level issue asking for a private channel.

The project does not support bypassing access controls, DRM, provenance protections, platform restrictions, or licensing controls.
